### A - OPL2 FM music (`src/mcport/opl*.h/.cpp` (new), `src/mcport/audio_*`, `sound.*`, `mcdata/hmp.*` / `sndbank.*`, `tests/opl_test.*`, report `docs/analysis/port_opl.md`, build dir `build_A`)

The music banks `music<set>-0.dat` are the OPL2 (AdLib / Sound Blaster FM) versions (`*.HMP`, HMI device
0xa002, instrument banks `data/inst.bnk` + `data/drum.bnk`); round 5 plays only the General MIDI bank (-2)
through the Windows MIDI mapper (`docs/analysis/port_audio.md`). Make the FM bank playable as the original
sounded on a Sound Blaster, with no MIDI device needed:
- A **software OPL2 (YM3812) emulator** written from the data sheet / public register documentation: 9
  two-operator channels + rhythm mode, all registers the driver writes (0x01 WSE, 0x08 CSM/NTS, 0x20-0x35
  AM/VIB/EGT/KSR/MULT, 0x40-0x55 KSL/TL, 0x60-0x75 AR/DR, 0x80-0x95 SL/RR, 0xA0-0xB8 F-num / block / key-on,
  0xBD AM/VIB depth + rhythm, 0xC0-0xC8 feedback / connection, 0xE0-0xF5 waveform), envelope generator with
  the rate tables, KSL / KSR, tremolo / vibrato LFOs, the four waveforms, operator feedback, output at
  49716 Hz resampled to the device rate. Accuracy target: close to the real chip by ear and by the published
  tables (log-sin / exp tables are fine); exact bit-accuracy is not required.
- The **HMI OPL MIDI driver behaviour**: how the HMI driver turns MIDI events into OPL register writes
  (instrument patch format of `inst.bnk` / `drum.bnk`, program change -> patch, drum channel 10 -> drum.bnk
  notes, voice allocation / stealing over the 9 (or 6 + rhythm) channels, note -> F-number / block tables,
  pitch bend range, velocity -> TL, controller 7 volume, CC 116/117, the `CSETUP` init). The driver code is
  in `MagicCarpet/magic/hmimdrv.386` (an HMI driver container, not in carpet.exe): find the OPL2 driver in
  it (ENGINE.md "HMI sound drivers", agent2_E / agent3_H / agent4_* notes), disassemble it with capstone
  (16- or 32-bit, find out) and reproduce it - this is the faithful part. Document the bank format in your
  report (FORMATS.md text for task E... E will not see it in time: put it in your report, the integrator
  merges it).

  `CLOCK_RENDER`) selected by `MC_MUSIC=opl` (and make it the default when no MIDI output device exists).
  `music_load_bank` must then load bank `-0` (sound.cpp decides which suffix by `g_music_device`; add what is
  needed). Keep `MC_MUSIC=midi` (GM through winmm) working; say which should be the default.
- Verification: `opl_test` (mc_unit_test with the synth sources, no SDL): the emulator by construction (a
  single sine operator at a known F-number gives the right frequency +-0.5 %, envelope timings for a few
  AR / DR / RR values against the data-sheet tables within 10 %, KSL / TL attenuation steps, waveform shapes,
