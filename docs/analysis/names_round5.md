## What was renamed and why

- **Creature states.** A creature's states are `type * 6 + {0 idle / type-specific, 1 main, 2 attack,
  3 follow, 4 dying, 5 dead}`. Under the old names the first state of every type carried the previous
  type's name. All 102 handlers are now `creature_<type>_s<N>_<role>_<addr>`. Roles that differ from
  the generic layout, taken from the port code and reports:
  - crab: 30 start, 33 collect_mana
  - genie: 66 vanish_appear, 67 hidden
  - skeleton: 54 rise
  - builder: 72 place_castle, 73 wander, 74 walk_to_castle, 75 pick_castle
  - townie / trader: noop states, and 82 / 88 dying = enter the castle or die
  - vulture: 6 seek_mana

  The disabled states 102..119 are `creature_s102_s107_nop_1f690` and so on.
  `creature_target_nearest_mana_ball_1aef0` -> `crab_target_nearest_mana_ball_1aef0`.
- **Class 3.**
  - 413a0 / 41500 / 416d0 -> `castle_active_update` / `castle_build_update` / `castle_destroyed_update`.
  - 402c0 -> `player_flyer_alive_update`, 11de0 -> `ai_wizard_update`, 40ab0 -> `player_dead_update`.
  - The empty handlers: 42520 -> `balloon_wait_nop`, 42760 -> `player_s10_nop`, 42960 ->
    `class8_update_nop`.
  - Constructors: types 1 / 2 / 3 -> `player_create_ai_wizard`, `castle_create`, `balloon_create`.
    Types 4..11 ("Flyer1..8") are start-position markers -> `player_create_start_pos0..7`.
- **Class 9.**
  - States: 45c70 = the lightning segment (state 14). 45c90 / 45e60 are the mana magnet (type 0x11,
    state 18) and smart bomb (type 0x12, state 19) shots. 45360 / 457a0 / 45b60 are the castle seed,

## Findings worth passing on

- **The music bank suffix in BRIEFING_round5.md task A is wrong.** The `.tab` record names show
  `music<set>-0` = OPL2 FM (`CGAME1.HMP`), `-1` = MT-32 (`CGAME1.ROL`), `-2` = General MIDI / AWE32
  (`CGAME1.GEN`). This agrees with `sound.h` (`g_music_device`), not with "0 General MIDI, 1 OPL2 FM, 2
  AWE32" in the briefing. A General MIDI player through the Windows MIDI mapper must load
  `music<set>-2`. Set 1 holds CINTRO4..6.
- Save game = 142 bytes raw (layout in FORMATS.md, from `fe_savegame_save_591d0`). It holds campaign
  progress and options, no game state.
- `movie/gam00000.dat` is the raw 0x38d03-byte GameState and `map00000.dat` the raw 0x612c2-byte
  terrain dump; neither is RNC-compressed.
- ENGINE.md still uses the old function names in its older sections (the in-place markers point to the
  new ones for the important cases). Port comments in `src/` also cite the old Ghidra names; they
  still identify the functions through the address suffix.
